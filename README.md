# Lab Exercise 2.1: HTML Elements and Attributes

## 📌 Introduction

This repository contains the completed exercises for **Lab Exercise 2.1: HTML Elements and Attributes**, as part of Chapter 2: HTML Part 1.

The purpose of this lab is to understand the basic structure of HTML documents, explore common HTML elements, and practice using HTML attributes to create simple webpages.

## 🎯 Objectives

- Understand the basic structure of an HTML document using `<html>`, `<head>`, and `<body>`.
- Identify and use common HTML elements.
- Learn how HTML attributes affect webpage elements.
- Create a simple personal profile webpage using HTML.
- Practice organizing HTML files and images in a GitHub repository.

## 📝 Lab Activities

### Part A: HTML Elements

Identify and match basic HTML elements with their correct functions.

Elements covered:
- `<!DOCTYPE html>`
- `<html>`
- `<body>`
- `<p>`
- `<br>`
- `<h3>`
- `<a>`

### Part B: Basic Structure of HTML

Create a basic HTML document containing the following elements:

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<title>`
- `<body>`
- `<h1>`
- `<p>`

This exercise demonstrates how a basic HTML webpage is structured.

### Part C: HTML Attributes

Explore and implement 10 HTML attributes.

| Attribute | Description |
|---|---|
| `id` | Assigns a unique identifier to an element |
| `class` | Groups elements under the same class |
| `href` | Specifies the destination of a hyperlink |
| `src` | Specifies the source of an image |
| `alt` | Provides alternative text for an image |
| `title` | Provides additional information about an element |
| `style` | Applies inline CSS styling |
| `disabled` | Disables an input element |
| `value` | Sets the value of an input element |
| `checked` | Preselects a checkbox |

### Part D: Personal Profile Webpage

Create a simple personal profile webpage containing:

- Main heading
- Personal picture
- Full name
- Matric ID
- Year of study
- Hometown address
- Website link to a local tourist attraction
